# FastAPI Practice Project

This project is a FastAPI-based backend application. Follow the instructions below to set up and run the development server locally.

## Prerequisites

Ensure you have Python installed on your system along with `uv` (optional, or use standard pip/venv).
uv add fastapi[standard]
uv add uvicorn[standard]

## Getting Started & Running the Server

If your virtual environment (`.venv`) is already created, activate it using the command prompt (Windows):

```bash
.venv\Scripts\activate


# Run Command
uv run uvicorn main:app --reload

```
